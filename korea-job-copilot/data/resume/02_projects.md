## Project: Korea Job-Search Copilot

Built an agentic pipeline that fetches job postings, extracts structured
requirements, retrieves relevant resume context via a custom RAG store,
drafts tailored cover letters, and runs a self-critique grounding check
before saving output. Reduced wasted drafting effort by filtering out
postings with blocking requirement gaps before any drafting API call.

---

## Project: PR Review Agent

Built a GitHub Action that uses an LLM tool-calling loop to read a pull
request diff, cross-reference it against repo style conventions, and post
review comments automatically. Deployed on personal repositories.
